Cómo usar la mesa de ayuda

  1. Ingresa con tu usuario y contraseña de GLPI.
  2. Selecciona un servicio y describe el problema, el resultado esperado y los pasos para reproducirlo.
  3. Guarda el número del ticket. Desde Mis tickets puedes consultar el estado, agregar respuestas y adjuntar evidencia.
  4. Cuando el equipo publique una solución, revísala y acepta o rechaza indicando el motivo.

Para probar ambos roles, usa ventanas de navegador separadas para el cliente y el técnico. Las credenciales locales se encuentran en el archivo .env.demo del proyecto.
